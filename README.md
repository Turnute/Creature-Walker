# Creature Walker

> Un simple jeu mobile basé sur les mécaniques du Pokéwalker, avec des créatures originales.

**Creature Walker** est le nom provisoire d'un jeu développé avec **Godot 4 et GDScript**, destiné à **Android et iOS**. Le projet reprend le principe d'un compagnon qui vous accompagne dans vos déplacements, avec un bestiaire original et une interface adaptée aux écrans modernes.

## Le concept

Marcher avec une créature, progresser au fil de ses pas et rencontrer de nouveaux compagnons à collectionner.

## État du projet

Le projet est au stade de **prototype**. Maintes fonctionnalités restent encore à développer.

## Ouvrir le projet

Importer le fichier `project.godot` dans Godot 4, puis lancer le projet depuis l'éditeur.
